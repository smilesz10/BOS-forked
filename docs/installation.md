# Installation Guide

## Prerequisites
- Git installed on your machine
- A server or local machine to self-host

## Steps

### 1. Clone the repository
```bash
git clone https://github.com/bos-com/BOS.git
cd BOS
```

### 2. Configure environment
Copy the example environment file and edit it:
```bash
cp .env.example .env
```
